# The Wire — practice concept preview

The current The Wire screen is an explicitly labelled, non-playable visual mockup in Cold Cases. It demonstrates the intended vertical club graph, fixed scoreboard, active-pair instruction and mobile hierarchy without starting a timer, accepting answers, calculating scores or storing records.

The preview emphasizes exactly two nodes—Barcelona and PSG—while completed Arsenal and upcoming Real Madrid nodes remain subdued. It uses existing local crest assets and makes no Worker or D1 request.

## Before gameplay implementation

The next milestone must generate and audit a local club-link graph from the reviewed Paper Trail histories. The coverage report must count eligible clubs, verified player-to-club relationships, valid unordered club pairs, usable distinct four-club routes and exclusions. Only verified senior first-team links available in the searchable player catalogue may become playable edges.

The intended playable rules remain: 90 seconds, any verified connecting player accepted, no accepted-player reuse within a session, a five-second penalty for incorrect guesses, a ten-second skip cost, and exponential ×1/×2/×4/×8/×16 combo scoring. None of those mechanics are represented as functional in the current preview.
